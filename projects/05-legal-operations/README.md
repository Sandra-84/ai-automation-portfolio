# AI Legal Navigator

> One entry point → intelligent routing → specialized workflows → relevant answer or human escalation.

## Problem

Legal teams receive repetitive questions, but different requests require different actions: information search, document-related tasks, consultation or specialist involvement.

## Solution

The AI agent analyzes the request and routes it to the appropriate workflow. Relevant information can be retrieved from the corporate knowledge base using RAG / Qdrant.

## How it works

User request → AI Legal Navigator → request classification → appropriate workflow → knowledge retrieval / action → response or human escalation.

## Capabilities

- Intelligent request routing
- Knowledge retrieval
- Specialized workflows
- Human escalation
- Automated responses

## Stack

n8n · OpenRouter · LLM · RAG · Qdrant · OpenAI Embeddings · Telegram · Gmail · Google Sheets
