# AI Voice Support Agent

## Problem

Support employees need fast access to product information and availability. Manual searching through tables and systems slows down responses.

## Solution

The AI voice agent accepts voice or text requests, understands the request, searches product information and returns the answer as text or voice.

## How it works

Voice / text request → input processing → speech-to-text → input normalization → AI Agent → product search → answer generation → text / voice response.

## Capabilities

- Voice-first support
- Multilingual AI
- Product knowledge search
- Automated responses

## Stack

n8n · Telegram · OpenRouter · ChatGPT-4 · 11Labs · Google Sheets · Qdrant
